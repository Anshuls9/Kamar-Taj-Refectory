npm init -y is used to install package.json which stores the backend project congfig and dependencies

server.js

Starts the Express server and connects the main application pieces.


config/

Database connection and application configuration.


models/

MongoDB schemas for users, meals, bookings and payments.


routes/

API endpoints such as login, meals and bookings.


controllers/

The actual logic for handling requests.


middlewares/

Authentication, role permissions, and request validation.


services/

Reusable business logic and Razorpay integration.


.env

Private credentials and environment settings. Never commit secrets to Git.



app.use() — tells Express to use some middleware or a router for matching requests.


React requests the data using fetch

React browser sends the request


useState stores the meals received from the backend so React can display them.
useEffect runs code after the dashboard renders. We'll use it to request the meals when the page loads.
